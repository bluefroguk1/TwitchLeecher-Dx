## Summary

- A summary bar with the search, Edit search, Hide downloaded, sort (newest,
  oldest, longest, most viewed) and grid/list view.
- For channel searches: the channel name and avatar with a star to add or
  remove it from favourites.
- Cards (three per row) with two-line titles and LIVE / CLIP / QUEUED /
  DOWNLOADED badges.
- Select all and "N selected · ~X GB" with a Download button for the
  selection.
